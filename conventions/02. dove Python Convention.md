## 1. 들어가며

- 이 문서는 작성자 dove의 Python 컨벤션을 정리한 것이다.
- 이 문서는 Python에 적용되는 공통 규칙과 Python 전용 규칙을 담는다.

### 1-1. 적용 기준

- 프로젝트 지침·설정을 우선하며, 그다음 이 문서와 공통 컨벤션을 차례로 적용한다.
- 공통 규칙은 [공통 코드 컨벤션](02.%20dove%20Common%20Convention.md)의 내용을 같은 `COM` ID로 이 문서에도 수록한 것이다. 공통 규칙을 변경할 때는 같은 ID를 가진 항목을 함께 갱신한다.
- 공통 규칙은 해당하는 코드 구조에 적용한다. 생애주기 배치를 모든 모듈에 동일하게 요구하지 않는다.
- 영역 구분에는 `PY-REGION-01`·`PY-REGION-02`를, 함수·클래스 정의의 간격에는 `PY-BLANK-01`·`PY-BLANK-01.1`을, 제어문의 범위에는 `PY-BLANK-02`·`PY-BLANK-02.1`을 적용한다.

| ID | 강도 | 규칙 |
|---|---|---|
| PY-STYLE-01 | Should | 프로젝트 지침·설정과 본 컨벤션에서 별도로 정한 규칙 외에는 [PEP 8](https://peps.python.org/pep-0008/)을 따른다. |

### 1-2. 규칙 강도

| 강도 | 의미 |
|---|---|
| Must | 반드시 준수한다. |
| Should | 특별한 이유가 없다면 준수한다. |
| May | 상황과 의도에 따라 선택할 수 있다. |
| Must Not | 사용하지 않는다. |
| Should Not | 특별한 이유가 없다면 사용하지 않는다. |

### 1-3. 규칙 표기

- 규칙은 `ID`, `강도`, `규칙` 열을 가진 표로 작성한다.
- ID는 `범위-분류-번호` 형식이다. 예: `COM-BLANK-01`
- 상위 규칙을 구체화하는 세부 규칙은 상위 규칙 번호 뒤에 `.번호`를 붙이고, 표에서 상위 규칙 바로 아래에 둔다. 세부 번호는 1부터 순서대로 붙인다. 예: `COM-BLANK-01.1`
- 범위는 공통 규칙이 `COM`, Python 전용 규칙이 `PY`이다. 이 문서에 수록한 공통 규칙은 공통 코드 컨벤션과 같은 `COM` ID를 사용한다.
- 규칙에 딸린 짧은 설명과 예시는 같은 칸에 적는다. 코드 예시는 표 아래에 두고, 어떤 규칙의 예시인지 ID로 밝힌다.
- 한 번 부여한 ID는 규칙의 위치가 바뀌어도 유지하고, 삭제한 규칙의 ID는 재사용하지 않는다. 새 규칙에는 같은 분류의 마지막 번호 다음 번호를 붙인다.

## 2. 코드 컨벤션

### 2-1. 명명 컨벤션

#### 2-1-1. 기준

식별자 이름은 해당 요소의 핵심 역할이 바로 드러나도록 짓는다.

#### 2-1-2. 구체적인 이름 사용

| ID | 강도 | 규칙 |
|---|---|---|
| COM-NAME-01 | Should | 숫자나 모호한 이름보다, 의미가 드러나는 구체적인 이름을 우선한다. |

### 2-2. 구조 컨벤션

#### 2-2-1. 영역 구분 규칙

Python에서는 고정 영역 구분 대신 역할별 묶음을 사용하고, 영역 주석은 필요한 경우에만 둔다.

| ID | 강도 | 규칙 |
|---|---|---|
| PY-REGION-01 | Should | 멤버를 역할별로 모아 배치한다. |
| PY-REGION-02 | May | 이름과 배치만으로 역할 구분이 어려울 때 영어 영역 주석을 사용할 수 있다. 고정 영역 이름과 장식용 구분선은 요구하지 않는다. |

#### 2-2-2. 빈 줄 규칙

함수·클래스 정의의 간격에는 일반적인 논리적 묶음의 간격보다 `PY-BLANK-01`·`PY-BLANK-01.1`을 우선 적용한다.

| ID | 강도 | 규칙 |
|---|---|---|
| COM-BLANK-01 | Should | 일반적인 논리적 묶음이나 영역 사이는 빈 줄 한 줄로 구분한다. |
| COM-BLANK-01.1 | May | 진입부와 진출부는 본문과 별도의 논리로 보고 빈 줄 한 줄로 구분할 수 있다. 진입부는 조기 반환 검사와 그에 바로 딸린 상태 변경이며, 그 안에서는 제어문 뒤의 빈 줄을 생략할 수 있다. 진출부는 마지막 반환이다. 코드가 짧거나 흐름이 명확하면 구분을 생략할 수 있다. |
| COM-BLANK-02 | Should | 제어문의 앞뒤에는 빈 줄 한 줄을 두되, 블록의 시작과 끝에는 두지 않는다. `if`와 `else`는 하나의 제어문으로 본다. 제어문과 직접 연관된 선언은 제어문의 일부로 보고 붙여 쓸 수 있으며, 이때 빈 줄은 선언 위에 둔다. `else` 없는 한 줄 `if`가 이어지면 서로 붙여 쓸 수 있다. |
| PY-BLANK-01 | Should | 모듈 최상위 함수·클래스 정의의 앞뒤는 빈 줄 두 줄로, 클래스 안의 메서드 정의 사이는 빈 줄 한 줄로 구분한다. |
| PY-BLANK-01.1 | May | 더미 구현처럼 밀접하게 관련된 한 줄 함수·메서드 정의의 묶음은 정의 사이의 빈 줄을 생략할 수 있다. `@overload` 같은 데코레이터 줄은 줄 수에 포함하지 않는다. |
| PY-BLANK-02 | Should | `COM-BLANK-02`의 제어문에는 `if`·`for`·`while`·`try`·`with`·`match`를 포함한다. `elif`·`else`·`except`·`finally`는 앞선 문과 하나의 제어문으로 본다. |
| PY-BLANK-02.1 | May | 본문이 한 줄의 단순 문장이고 `elif`·`else`가 없는 `if`는 `COM-BLANK-02`의 한 줄 `if`로 보고 서로 붙여 쓸 수 있다. |

`PY-BLANK-01`의 예시이다. 모듈 상수와 함수, 함수와 클래스 사이는 빈 줄 두 줄로 구분하고, 클래스 안에서는 빈 줄 한 줄로 구분한다.

```python
import json

DEFAULT_PATH = "settings.json"


def load_settings(path: str = DEFAULT_PATH) -> dict[str, object]:
    with open(path, encoding="utf-8") as file:
        return json.load(file)


class Settings:
    timeout = 30

    def __init__(self, values: dict[str, object]) -> None:
        self.values = values

    def get(self, key: str) -> object:
        return self.values[key]
```

`PY-BLANK-01.1`의 예시이다. `Protocol`의 더미 구현과 `@overload` 묶음은 정의 사이의 빈 줄을 생략한다.

```python
from typing import Protocol, overload


class Source(Protocol):
    def open(self) -> None: ...
    def read(self) -> bytes: ...
    def close(self) -> None: ...


@overload
def parse(value: int) -> int: ...
@overload
def parse(value: str) -> str: ...


def parse(value: int | str) -> int | str:
    return value
```

`COM-BLANK-02`와 `PY-BLANK-02`의 예시이다. `try`부터 `finally`까지, `if`부터 `else`까지를 각각 하나의 제어문으로 보고 앞뒤에 빈 줄을 둔다. `size`는 `try`와 직접 연관된 선언이므로 붙여 쓴다.

```python
def describe(path: Path) -> str:
    size = None
    try:
        size = path.stat().st_size
    except FileNotFoundError:
        log_missing(path)
    finally:
        count_lookup(path)

    if size is None:
        label = "missing"
    elif size == 0:
        label = "empty"
    else:
        label = "file"

    return label
```

`PY-BLANK-02.1`의 예시이다.

```python
if name:
    parts.append(name)
if title:
    parts.append(title)

send(parts)
```

`COM-BLANK-01.1`의 예시이다. 진입부의 조기 반환 검사와 상태 변경은 붙여 쓰고, 마지막 반환은 본문과 구분한다.

```python
def close(self) -> int:
    if self._closed:
        return 0
    self._closed = True

    released = self._release_all()
    self._notify()

    return released
```

#### 2-2-3. 메서드 배치 규칙

| ID | 강도 | 규칙 |
|---|---|---|
| COM-ORDER-01 | Should | 메서드는 가능한 한 생애주기 순서로 배치한다. |
| COM-ORDER-02 | Should | 같은 생애주기 단계에서는 논리적으로 관련된 기능끼리 묶어 배치한다. |
| COM-ORDER-03 | Should | 각 기능 묶음 안에서는 사용 흐름에 따라 배치한다. |

생애주기 순서는 생성·사용·정리 단계가 있는 대상에 적용한다. 배치 기준은 다음과 같이 큰 흐름에서 세부 흐름으로 적용한다.

1. **생애주기 순서**: 생성·초기화 → 일반 동작 → 정리 순서로 배치한다.
2. **논리 순서**: 같은 생애주기 단계의 메서드를 관련 기능별로 묶어 배치한다. 예: 노드 관리 → 세그먼트 관리.
3. **사용 흐름**: 각 기능 묶음 안에서 기능을 사용하는 일반적인 절차에 따라 배치한다. 예: 등록 → 조회 → 삭제.

생애주기 단계가 없는 함수 중심 모듈에는 논리적 묶음과 사용 흐름에 따른 배치 원칙을 적용한다.

### 2-3. 문자열 컨벤션

#### 2-3-1. 문자열 리터럴과 내용의 인용

| ID | 강도 | 규칙 |
|---|---|---|
| PY-QUOTE-01 | Should | 문자열 리터럴을 감싸는 따옴표는 큰따옴표(`"`)를 기본으로 한다. 불필요한 이스케이프를 줄여 가독성을 높일 때는 작은따옴표를 사용할 수 있다. |
| PY-QUOTE-02 | Should | 주석이나 문자열 내용 안에서 단어나 구절을 인용할 때는 작은따옴표(`'`)를 기본으로 한다. docstring 내용에도 적용하되, 원문이나 데이터·코드의 정확한 표기를 보존해야 할 때는 예외로 한다. |

문자열을 감싸는 따옴표와 내용 안의 인용 부호는 역할이 다르다. 아래 예시에서 `print("Hello")`의 큰따옴표는 문자열 리터럴의 구분자이고, 주석의 작은따옴표는 출력할 내용을 구분하는 인용 부호이다.

`PY-QUOTE-01`과 `PY-QUOTE-02`의 예시이다.

```python
# Print 'Hello' below.
print("Hello")

message = "Select 'Run' to continue."
```

`PY-QUOTE-01`의 이스케이프 예외이다. 아래 문자열은 원문에 있는 큰따옴표를 유지하면서 이스케이프를 피하기 위해 작은따옴표로 감싼다.

```python
quoted_text = 'She said, "Hello".'
```

#### 2-3-2. 삼중 따옴표 규칙

| ID | 강도 | 규칙 |
|---|---|---|
| PY-QUOTE-03 | Should | docstring과 그 밖의 삼중 따옴표 문자열은 삼중 큰따옴표(`"""`)로 감싼다. 한 줄 docstring에도 적용한다. |

이 규칙은 [PEP 8](https://peps.python.org/pep-0008/)의 String Quotes 절과 [PEP 257](https://peps.python.org/pep-0257/)의 docstring 표기 기준을 따른다.

`PY-QUOTE-03`과 `PY-QUOTE-02`의 예시이다.

```python
def print_greeting() -> None:
    """Print 'Hello' to standard output."""
    print("Hello")


help_text = """Select 'Run' to start.
Select 'Stop' to finish."""
```
