# 번역

- 문서 파일(`.md`, `.txt` 등)을 제외한 파일은 변경하지 않는다. 특히 번역 시 코드 파일(`.cs` 등)은 건드리지 않는다.
- 기존 번역이 존재할 경우 원문의 변경 사항과 기존 번역의 오류를 바로잡되, 변경되지 않은 번역과 기존 용어는 최대한 보존한다.
- 번역 문서는 원문 문서와 파일, 제목, 절, 표, 코드 블록, 문단의 구조와 의미 단위가 1:1로 대응되도록 작성한다. 문장은 직역하지 않고 번역 언어에 자연스럽게 작성한다.
- 코드 블록의 코드, 식별자, 파일 경로, URL은 번역하지 않는다.
- 문서가 단일 언어이거나 둘 이상의 언어 중 대표 언어라면 `README.md`처럼 언어 코드를 생략할 수 있다. 대표 언어가 아닌 추가 언어 문서나 언어를 명시하려는 문서에는 원문 파일명과 확장자 사이에 언어 코드를 붙여 `README.en.md`, `README.ko.md`처럼 작성한다.
- 폴더 내에 `TranslationGuide.md` 파일이 있는 경우, 해당 폴더의 번역은 해당 파일에 적힌 지침을 우선하여 따른다.
