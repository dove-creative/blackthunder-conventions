# 네이밍

## 목적

이 문서는 패키지명, 어셈블리명, 네임스페이스, 표시 이름처럼 같은 개념을 서로 다른 위치에 적을 때 어떤 표기 방식을 사용할지 정리한다.

이름은 사용되는 표면에 따라 역할이 다르다. 배포 시스템이 읽는 식별자는 외부 생태계의 규칙을 우선하고, C# 코드에서 드러나는 식별자는 C# API와 dove C# 컨벤션을 우선한다.

## 기본 원칙

- 같은 대상을 가리키더라도 패키지 식별자와 코드 식별자는 같은 대소문자를 강제하지 않는다.
- 설치, 배포, 경로, 레지스트리 식별자는 해당 생태계의 관례를 우선한다.
- C# 네임스페이스와 어셈블리 이름은 코드에서 읽히는 표면이므로 PascalCase 세그먼트를 우선한다.
- 사용자가 보는 표시 이름은 식별자 규칙보다 읽기 쉬운 자연어 표기를 우선한다.

## .NET 패키지 식별자

.NET 패키지의 `PackageId`는 소유자명과 제품명을 `.`으로 구분하고, 각 세그먼트는 PascalCase로 작성한다.

예:

```xml
<PropertyGroup>
  <PackageId>BlackThunder.UniEngine</PackageId>
</PropertyGroup>
```

이 이름은 설치, 배포, 패키지 해석에 사용되는 식별자이다. 다른 패키지와 충돌하지 않도록 소유자명부터 시작하고, 동일한 제품군은 공통 접두사를 사용한다.

패키지 식별자는 패키지의 소유자와 제품을 안정적으로 나타내도록 작성한다. 다만 배포 생태계에 별도의 규칙이 있다면 해당 규칙을 우선한다.

예:

```text
BlackThunder.UniEngine
```

## C# 네임스페이스

C# 네임스페이스는 코드 API의 일부이므로 회사명 또는 소유자명에서 시작하고, 각 세그먼트는 PascalCase로 작성한다.

예:

```csharp
namespace BlackThunder.UniEngine
{
}
```

같은 런타임 소스를 여러 프로젝트에서 공유하는 경우에도 네임스페이스는 동일하게 유지한다. 사용 환경에 따라 네임스페이스가 달라지면 샘플, 테스트, 문서의 `using` 구문이 갈라지고 공개 API가 불안정해진다.

## 어셈블리 이름과 RootNamespace

어셈블리 이름은 어셈블리의 주된 목적이 드러나도록 작성한다. `RootNamespace`는 포함 리소스의 이름을 구성하기 위한 기준이 필요할 때 설정한다.

예:

```xml
<PropertyGroup>
  <AssemblyName>BlackThunder.UniEngine</AssemblyName>
</PropertyGroup>
```

테스트, 샘플, 도구처럼 하위 어셈블리가 필요하면 대표 어셈블리 이름 뒤에 PascalCase 세그먼트를 붙인다.

예:

```text
BlackThunder.UniEngine.Tests
BlackThunder.UniEngine.Samples
BlackThunder.UniEngine.Tools
```

프로젝트 파일명도 어셈블리 이름과 맞추는 것을 기본으로 한다.

예:

```text
BlackThunder.UniEngine.csproj
BlackThunder.UniEngine.Tests.csproj
```

`RootNamespace`는 C# 소스에 선언된 네임스페이스를 변경하지 않는다. 포함 리소스의 이름을 구성할 때 별도의 기준이 필요한 경우에만 명시한다.

## 표시 이름

사용자가 보는 이름은 식별자보다 읽기 쉬운 표기를 우선한다. 패키지 제목, 샘플 이름, 문서 제목은 공백과 약어를 자연스럽게 사용할 수 있다.

예:

```text
UniEngine
Native C# Usage
```

## 혼동 방지

아래처럼 표면을 섞지 않는다.

- 패키지 식별자나 어셈블리 이름에 `BlackThunder UniEngine`처럼 공백을 사용하지 않는다.
- C# 네임스페이스에 `blackthunder.uniengine`처럼 전부 소문자인 식별자를 그대로 쓰지 않는다.
- 표시 이름이 필요한 곳에는 `BlackThunder.UniEngine` 같은 코드 식별자보다 `UniEngine`처럼 읽기 쉬운 이름을 사용한다.

요약하면, 배포 식별자와 코드 식별자는 `BlackThunder.UniEngine`, 사용자 표시 이름은 `UniEngine`처럼 쓴다.
