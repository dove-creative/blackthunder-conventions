# AGENTS 템플릿

## 1. 목적

이 문서는 프로젝트 루트 `AGENTS.md`의 일반용 및 C#용 기본 형식을 제공한다.

템플릿은 프로젝트 문서와 BlackThunder Conventions를 작업 전에 확인하게 하고, 대화·파일·검증에 관한 공통 작업 규칙을 에이전트에게 전달하는 것을 목적으로 한다.

## 2. 사용 방법

프로젝트의 언어와 환경에 맞는 템플릿을 선택하여 프로젝트 루트의 `AGENTS.md`로 복사한다. 프로젝트의 문서 위치, 컨벤션 서브모듈 경로, 언어 정책, 지원 프레임워크, 테스트 정책이 다르다면 해당 항목을 실제 환경에 맞게 수정한다.

BlackThunder Conventions를 다른 경로에 두거나 사용하지 않는 프로젝트에서는 관련 경로와 서브모듈 확인 규칙을 수정하거나 제거한다.

## 3. 일반용 AGENTS 템플릿

```markdown
# AGENTS

## 기본 규칙

- 한국어로 대화할 때는 존댓말을 사용한다.
- 프로젝트 문서는 `docs` 폴더에 존재한다. 작업 시작 전, 관련 문서가 존재하는지 확인하고, 존재할 경우 해당 내용을 숙지한 후 작업을 시작한다.
- 공통 컨벤션과 작업 지침은 `guidelines/blackthunder-conventions`에 존재한다. 해당 경로가 없거나 비어 있다면 서브모듈이 초기화되지 않았을 수 있으므로 사용자에게 알린다.

## 컨벤션

- 이 작업공간에서 코드 파일을 새로 작성하거나 수정할 때는 줄 끝을 Unix 형식인 `LF`로 유지한다.
- 일부 코드 파일은 UTF-8이 아닐 수 있다. `apply_patch`가 `invalid utf-8 sequence`로 실패하면 파일 손상으로 판단하지 말고, PowerShell/.NET에서 기존 인코딩으로 읽은 뒤 필요한 범위만 UTF-8로 저장한다(.md 등 단순 문서 파일의 경우 인코딩 검사를 하지 않아도 된다).
- 코드 및 문서 작업 시, 별도 지침이 없다면 `guidelines/blackthunder-conventions/conventions`의 해당 컨벤션을 따른다.
- 작업 유형에 해당하는 구체적인 지침이 `guidelines/blackthunder-conventions/instructions`에 존재한다면 해당 지침을 따른다.
- 코드 내 주석은 영어를 사용한다.
- Git 커밋 제목은 영어를 사용한다.

## 정보

- 사용자가 명시적으로 테스트 실행을 요청하지 않은 경우 테스트를 실행하지 않는다. 필요한 확인은 빌드, 정적 검색, 문서 검사처럼 테스트가 아닌 검증으로 한정하고, 테스트가 필요하면 먼저 사용자에게 확인한다.
```

## 4. C#용 AGENTS 템플릿

```markdown
# AGENTS

## 기본 규칙

- 한국어로 대화할 때는 존댓말을 사용한다.
- 프로젝트 문서는 `docs` 폴더에 존재한다. 작업 시작 전, 관련 문서가 존재하는지 확인하고, 존재할 경우 해당 내용을 숙지한 후 작업을 시작한다.
- 공통 컨벤션과 작업 지침은 `guidelines/blackthunder-conventions`에 존재한다. 해당 경로가 없거나 비어 있다면 서브모듈이 초기화되지 않았을 수 있으므로 사용자에게 알린다.

## 컨벤션

- 이 작업공간에서 `.cs`, `.csproj`, `.props`, `.targets`, `.sln`, `.slnx` 파일을 새로 작성하거나 수정할 때는 줄 끝을 Unix 형식인 `LF`로 유지한다.
- 일부 코드 파일은 UTF-8이 아닐 수 있다. `apply_patch`가 `invalid utf-8 sequence`로 실패하면 파일 손상으로 판단하지 말고, PowerShell/.NET에서 기존 인코딩으로 읽은 뒤 필요한 범위만 UTF-8로 저장한다(.md 등 단순 문서 파일의 경우 인코딩 검사를 하지 않아도 된다).
- C# 코드 작업 시, 별도 지침이 없다면 `guidelines/blackthunder-conventions/conventions/dove CSharp convention.md`를 따른다.
- 문서 작업 시, 별도 지침이 없다면 `guidelines/blackthunder-conventions/conventions/dove documentation convention.md`를 따른다.
- 작업 유형에 해당하는 구체적인 지침이 `guidelines/blackthunder-conventions/instructions`에 존재한다면 해당 지침을 따른다.
- 코드 내 주석은 영어를 사용한다.
- Git 커밋 제목은 영어를 사용한다.

## 정보

- Unity 등 최신 C# 문법을 완전히 지원하지 않는 프레임워크와의 호환성을 위해 nullable 표기법을 사용하지 않는다. 이로 인해 발생하는 nullable 관련 경고는 무시할 수 있다.
- 사용자가 명시적으로 테스트 실행을 요청하지 않은 경우 테스트를 실행하지 않는다. 필요한 확인은 빌드, 정적 검색, 문서 검사처럼 테스트가 아닌 검증으로 한정하고, 테스트가 필요하면 먼저 사용자에게 확인한다.
```

## 5. 검증 기준

- 파일명이 프로젝트 루트의 `AGENTS.md`인지 확인한다.
- 프로젝트 문서와 컨벤션 경로가 실제 구조와 일치하는지 확인한다.
- C#용 템플릿을 사용할 때는 지원 프레임워크가 nullable 표기법을 지원하는지 확인하고, 해당 제한을 유지할지 결정한다.
- 프로젝트에서 사용하지 않는 언어·커밋·테스트 규칙은 제거하거나 수정한다.
- LF 정책을 사용한다면 해당 파일 형식을 `.gitattributes`나 편집기 설정에도 반영한다.
